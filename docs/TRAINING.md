# Training and experiment guide

## Environment and memory

Python 3.10+, NumPy and PyTorch. VTK/PyVista are optional converters; Matplotlib is optional reporting. Install PyTorch appropriate to your GPU environment; `tsml doctor` reports the actual setup.

The paper model has 15.77M parameters. Higher-order derivatives use FP32 and the explicit attention-weight path. Gradients accumulate across memory microbatches. Lower `microbatch_size` to save memory while retaining `batch_size=4096`.

## Train and resume

```bash
tsml train --config configs/paper.json --manifest data/prepared/manifest.json --output runs/c1 --mode final --seed 1337 --device cuda
tsml train --config configs/paper.json --manifest data/prepared/manifest.json --output runs/c1 --mode final --seed 1337 --device cuda --resume
```

New runs refuse to overwrite directories. Resume requires matching configuration, seed, mode and manifest. Each completed epoch atomically saves `latest.pt`. A mid-epoch interruption restarts that epoch. History restores from the checkpoint, avoiding duplicated log rows.

| File | Contents |
|---|---|
| `latest.pt` | Model, Adam state, RNGs, config, history and provenance |
| `stage1.pt`, `stage2.pt`, `stage3.pt` | Compact completed-stage model snapshots |
| `history.csv` | Stage, epoch, warm-up flag, objective |
| `normalization.json` | Fitting moments and exact fitted IDs |
| `run.json` | Config, seed, split, manifest hash, runtime and data identity |

Adam checkpoint files are larger than model weights because they contain optimizer moments. They are generated by training, not shipped as fake pretrained artifacts.

## Selection and independent runs

Use `--mode selection` for 128/32 fitting/validation. Select hyperparameters using validation IoU alone. Use `--mode final` for fresh 160/40 retraining/testing. Defaults contain the selected paper settings; automatic baseline grid searches are outside this TSML-focused repository.

```bash
tsml experiment --config configs/paper.json --manifest data/prepared/manifest.json --output experiments/c1 --seeds 1337 2024 3407 --mode final --device cuda
tsml aggregate --summaries results/a/summary.json results/b/summary.json results/c/summary.json --output results/aggregate
```

Experiment runs execute sequentially. Aggregation checks unique seeds and matching config/data/split identities. It computes mean and **sample SD across per-run temporal averages**, not pooled point-level SD.

## Metrics and figures

```bash
tsml evaluate --checkpoint runs/c1/stage3.pt --manifest data/prepared/manifest.json --output results/c1 --device cuda --save-predictions
tsml plot --run runs/c1 --evaluation results/c1 --output figures/c1
```

Classification uses original-grid labels at alpha_L < 0.90. Occupancy error is the absolute difference in volume-weighted cavity fractions. Velocity MAE compares magnitudes; pressure MAE compares spatially demeaned pressure; phase MAE compares liquid fractions. Metrics are averaged over snapshots.

Empty/empty cavity masks have IoU=F1=1. Precision is 1 if both are empty, otherwise 0 when only predictions are empty.

## Troubleshooting

| Symptom | Action |
|---|---|
| Expected 200 snapshots | Supply actual sequence; synthetic examples are not CFD replacements |
| No cavitating points | Check phase convention; fixed enrichment cannot use an empty pool |
| SHA256 mismatch | Check the changed file against its manifest |
| Resume settings differ | Restore original settings or start a new run |
| GPU out of memory | Reduce microbatch size, retain effective batch |
| Nonfinite loss | Check units, pressure zero, physical constants and normalization |
| Legacy weights rejected | Retrain the revised architecture/loss |

CPU epoch-resume equivalence is tested. Bitwise equality across GPU types, software versions or devices is not guaranteed. Epoch count is not a wall-time estimate.
